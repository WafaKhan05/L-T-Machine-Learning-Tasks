# L&T Machine Learning Tasks

This repository contains the Machine Learning tasks completed as part of my L&T learning program.

## Contents

The repository includes 7 practical Machine Learning tasks covering different concepts, algorithms, data preprocessing techniques, model building, and evaluation.

| Task    | Description              |
| ------- | ------------------------ |
| Task 01 | Implement Data Cleaning and Basic Feature Engineering Techniques to Prepare Data for a Movie Recommendation System. |
| Task 02 | Model Selection with Cross-Validation-Balancing Bias and Variance |
| Task 03 | Housing Price Prediction - Linear Regression vs. Random Forest |
| Task 04 | Handwritten Digit Recognition - Comparing KNN, Random Forest and Decision Tree |
| Task 05 | Dimensionality Reduction with PCA |
| Task 06 | Handwritten Digit Recognition with Neural Networks |
| Task 07 |Image Classification with Convolutional Neural Networks. |
